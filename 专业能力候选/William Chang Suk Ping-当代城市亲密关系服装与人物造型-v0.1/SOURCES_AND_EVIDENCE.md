# 来源、证据与适配边界

## 证据等级

- A：主体本人直接访谈或明确陈述。
- B：博物馆、学院、奖项机构等可定位资料。
- C：长期合作主创对共同创作过程的陈述；只能支持合作系统，不能把每个决定单独归因于主体。
- D：本系统根据项目任务形成的分析性适配；需要通过实际项目继续验证。

## 明确不宣称的内容

1. 不宣称本候选能够复现或替代张叔平本人。
2. 不宣称所有方法都是主体逐字提出；分析性结构均已标记。
3. 不宣称《花样年华》的每项服装决定都可单独归因于张叔平。
4. 不把 LEMAIRE 的品牌语言写成张叔平方法。
5. 不把国外日常服饰结论直接当成当代中国城市穿衣事实。
6. 不以奖项、名气或作品辨识度替代方法验证。

## 当前证据缺口

- 尚缺不同收入、城市和职业的当代中国真实衣橱观察样本。
- 尚缺同一人物在多个场戏中的服装连续性验证。
- 已确认当前模型会把未设结构识别点的“简洁廓形”误解为宽大、灰旧、普通户外或基础职场款；需要继续验证修订后的结构阈值。
- 尚未验证本方法对体型差异、夏季、高饱和项目和群像的适用性。
